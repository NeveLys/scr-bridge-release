# SCR Bridge — Release

Публичный репозиторий с готовыми APK-сборками SCR Bridge для тестировщиков.

Исходный код здесь не публикуется — только релизы (вкладка **Releases** справа).
Каждый релиз содержит подписанный `.apk`, тег релиза = versionCode приложения.

Для установки: скачай `.apk` из последнего релиза, разреши установку из
неизвестных источников при запросе, установи.
